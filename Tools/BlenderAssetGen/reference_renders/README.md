# Reference renders

A visual regression baseline: one screenshot per bundled asset, generated by
`build_reference_renders.py`. Regenerate after any asset-generation change and diff the
PNGs by eye against what's committed here — that's the review step, this directory doesn't
enforce a pixel-exact match automatically (lighting/AA noise makes exact comparison brittle).

```
blender --background --factory-startup --python Tools/BlenderAssetGen/build_reference_renders.py
```

These are blockout-tier renders (see `Docs/KINGMAKER_XR13_ASSET_PIPELINE.md`), not final art —
they exist to catch an asset silently breaking or regressing, not to demonstrate quality.
