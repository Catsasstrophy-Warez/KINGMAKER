# Kingmaker action reference matrix

This is a visual and gameplay reference matrix for future concept generation and RealityKit asset authoring. It is not a claim that the scenes or assets are complete.

| Track | Reference beats |
|---|---|
| Vehicular combat | Highway pursuit, side-swipe sparks, overboost launch, night engagement, in-cabin telemetry |
| Salvage and repair | Heavy tow, engine transplant, diagnostic bypass, suspension strain |
| Infrastructure | Refinery Kingdom, valve station bypass, Rail Yard, instrument calibration |
| Weather | Thermal shock, Barrens whiteout, frozen pass, blackout evasion |
| Faction configurations | Heavy Hauler, Flame Spitter, High-Tech Scavenger, Nomad |

Every reference must preserve the XR-13's coherent silhouette and fictional identity while making the mechanical consequence of the chosen build visible.
