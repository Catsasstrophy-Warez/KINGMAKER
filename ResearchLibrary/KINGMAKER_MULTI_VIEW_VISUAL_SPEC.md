# Blackridge XR-13 “Kingmaker” — Multi-View Visual Specification

This specification defines the modeling and image-reference set for the Kingmaker. It is a target for production assets, not a claim that the ten views are already rendered.

## Restored engineering views

1. Front orthographic: broad fictional XR-13 grille, compact LED clusters, hood-mounted supercharger intake, performance tires, and clean workshop floor.
2. Side orthographic: long hood, rearward greenhouse, fastback roof, wide haunches, carbon splitter/side skirts, alloy wheels, and large brakes.
3. Rear orthographic: fastback hatch, active-aero wing, segmented lamps, diffuser, dual exhaust, and visible rear drivetrain density.
4. Top-down: hood extraction, supercharger cowl, clean roofline, active rear wing, and diffuser geometry.
5. Underbody: V8, DCT housing, carbon driveshaft, pushrod/MagneRide suspension, exhaust routing, and dry-sump pan.
6. Engine bay: Roots-style supercharged V8, reinforced shock towers, coolant hoses, headers, belt drive, fuel lines, and industrial radiator.
7. Suspension/brakes: dust-coated six-piston caliper, heat-stressed rotor, long-travel damper, pushrod geometry, and sensor wiring.

## Operator environment

8. Cabin: roll cage, stripped aluminum floor, custom pedal box, racing seat, old fastback dashboard, passenger diagnostic equipment, and visible fuel-cell enclosure.
9. Dashboard: analog tachometer, rugged diagnostic computer, industrial toggle panel, fuel/ignition/fan controls, and SocketCAN wiring.

## Wasteland target

10. Elevated isometric Blacktop view: oxidized black and red primer panels, welded repairs, armored push bar, recovery winch, roof cargo, exposed supercharger, all-terrain tires, dust, headlights, broken guardrail, and DEAD END signage. The vehicle must remain recognizable as the same restored XR-13.

## Consistency constraints

- Original fictional design; no real-world badges or copied production details.
- Preserve the same roofline, greenhouse, hood relationship, shoulder volume, and wheelbase across all configurations.
- Every visible mechanical feature must map to a simulation component, upgrade path, failure state, or interaction.
- Dashboard text and technical labels are references for authored UI assets, not runtime assumptions until localized production assets exist.
