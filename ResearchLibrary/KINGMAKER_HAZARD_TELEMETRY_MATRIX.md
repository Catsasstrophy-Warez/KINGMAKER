# Kingmaker hazard and telemetry reference matrix

| Track | Reference beats |
|---|---|
| Hazard shielding | Explosion-proof firewall, Class I Div 1 interceptor, intrinsically safe cabin, compressor station |
| Racing | Mid-Ohio Valley dirt survivor, Blacktop high-speed duel, E85 conversion, car-show ruins |
| ECU/telemetry | VCM scanner, SocketCAN override, as-built hex modification, windshield telemetry overlay |
| Instrumentation | Rosemount bypass, Fisher valve throttle, Gas Clip monitor, Tremec teardown |

Design rule: every industrial or telemetry object must either protect the player, reveal a system state, enable a repair/tuning action, or create a new environmental risk.
